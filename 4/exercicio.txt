O exercício é Formatação de Catálogo.

O objetivo é criar uma função formatarProdutos(produtos) que retorne um novo array contendo os mesmos produtos, 
mas com uma nova propriedade adicionada a cada um deles.
As regras são:

Transformação: Cada objeto deve ganhar uma nova propriedade chamada precoFormatado.

Formatação: O valor dessa propriedade deve ser uma string no formato "R$ X.XX" (por exemplo: "R$ 120.00").

Imutabilidade: O array produtos original não pode ser alterado.

Técnica: Use o .map() para percorrer o array e o Spread Operator (...item) para copiar as propriedades originais enquanto adiciona a nova.
